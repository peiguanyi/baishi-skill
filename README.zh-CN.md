# baishi 拜师

**为你的AI回答增加一个小尾巴，在有需要时给你一些提示词方面的建议。**

[English](README.md) · 简体中文 · [繁體中文（香港）](README.zh-HK.md)

“拜师”本是“拜认师傅”的意思，这里取其核心内涵，以 Skill 的形式，在合适的时机给你一些提示词优化小建议。

---

## 这个Skill适合谁？

**如果你是**用 AI 查资料、写点东西、改改文档、安排个行程，都是日常里的事，也从没研究过什么“提示词工程”，那这个 Skill 就是为你写的。

**如果你是**靠写提示词吃饭的人，或者平时已经在考虑上下文、示例、输出格式这些事，那你可能会觉得这个 Skill 能提供的东西太小儿科了。

## 你是否遇到过这种情况？

你让 AI 帮个忙，它回答了，但就是可能还不太满意。于是你补一句，再补一句。几轮下来，你终于得到了想要的东西。

如果有一个更合适的提示词的话，可以提高让AI辅助的效率。

拜师就是一个顺带给你一些提示词建议的小 Skill。

## 这个Skill大概是什么样的？

你照常跟 AI 说话。它偶尔会在回答最末尾附上一个小尾巴，顺带让你了解一下在当前的场景下如何优化提示词。

**写文案**

> **你：** 帮我写一份产品发布公告
>
> **AI：** *（你要的完整草稿）*
>
> 💡 提示词技巧参考：这类发布公告，写明目标读者、投放渠道和语气，初稿通常会离可用近很多；比如「为 Northwind Notes 写一段 120 字、面向自由职业设计师、发在微信公众号、语气温和克制的发布文案」这样的说法往往更好使。

**同一件事，换成其他语言问，比如英文** —— 你用什么语言，拜师skill给你的小建议就用什么语言

> **You:** help me find recent papers on sleep and memory consolidation
>
> **AI:** *(the full answer)*
>
> 💡 A prompt phrasing tip: For a literature search like this, naming the years, the population, and what you'll do with the findings narrows the results fast — for example, "find 2023–2026 studies on sleep and memory consolidation in adults over 60, for a patient handout."

**没什么可教的时候**

> **你：** 法国的首都是哪里？
>
> **AI：** 巴黎。

既然没什么可教的，那 AI 在正常回答完后就会结束。

## 大多数时候它是沉默的，并不会喋喋不休

比如下面这些时候，拜师给不了太好的建议，那就什么都不说：

- 你问的是一个简单事实问题，这种情况没必要打磨提示词。
- 你正使用AI进行一些复杂工作，或者正在和 AI 聊一些情绪问题时，这些时候并不希望被偶尔穿插的提示词小建议打扰。
- 你要求AI给出的回答必须是某个具体格式（比如 JSON、文件、表格）时，为避免小提示误入其中，还是保持沉默吧。
- AI在思考你的问题后对你提出了反问，这种情况下你的解释说明本身就已经实现了优化提示词的目的，那便不需要这个 Skill 再重复多嘴。
- 你原本的提示词就能够很好的解决问题、实现目的，那便无需多言。
- 如果AI自己本身的能力问题导致回答不太令人满意，并不是优化提示词能做出改变时，这个 Skill 便也不会做出反应。

## 安装

把下面这句话复制给你的 AI，剩下的它会自己完成。

```
请帮我安装这个 Skill：https://github.com/peiguanyi/baishi-skill
```

想自己动手的话：

1. 下载：在本页点 Code → Download ZIP，然后解压。
2. 放置：把文件夹放进你的 agent 读取 skill 的目录。
3. 重载：重启 Agent 或开个新会话，然后输入 `/baishi`或`/拜师`。

如果想要卸载，把 `baishi` 文件夹删掉就是了。

## 启用

装好之后，想要启用拜师时，输入下面任意一条即可：

```
/baishi
/拜师
/拜師
```

如果开启了新会话且仍需启用拜师，需要在新的会话中再此输入指令开启。

输入了没反应？可以看一看[疑难排查](#疑难排查)。

## 调整

你可能会想调整小尾巴的出现频率和内容长度，直接告诉 Agent 你的想法即可，但是这些调整只在你当前会话、当次 Skill 调用中生效。

## 关闭

明确告诉 Agent 你想要停止拜师就可以将它关掉，比如：

`停止拜师` · `关闭拜师` · `别给我建议了` · `不用你建议了`

## 重新启用

当关闭拜师后，再次输入 `/baishi`或`/拜师` 即可再次开启这个 Skill。

## 它到底在教什么

拜师给的是一条提示词改写建议，从来不是一套理论。

| 常缺的东西 | 提示会补上的 |
| --- | --- |
| 受众是谁 | 读者、受众、身份 |
| 使用场景 | 渠道、格式、载体 |
| 内容篇幅 | 字数、条数、章节数 |
| 语气设定 | 语气、正式程度 |
| 怎样算好 | 一小段你想要的成品示例 |
| 不要什么 | 限制条件、排除项 |

## 常见问题

**它会改动我的回答吗？**
不会。AI原本的完整回答永远排在第一位，这个 Skill 本身并不对 AI 的回答做出调整。

**它是一个提示词评价系统吗？**
不是。这个 Skill 不会去评判你的提示词，它只在部分情况下给你一些建议。

**它会把我的内容上传到什么地方去吗？**
不会。这个 Skill 的本质就只是一个 Markdown 文件，不跑代码，也不会将你的会话上传至某个地方。

**在英文或其他语言的情况下可以使用这个 Skill 吗？**
可以。这个 Skill 的小尾巴会使用你在会话中所用的语言。

**可以将拜师和其他 Skill 一起用吗？**
可以。拜师只在你的 AI 回答的末尾附带一个小尾巴，具体的回答内容是否由其他 Skill 运行达成并不会影响拜师。

**我开启了拜师，但是几轮对话下来一直没看到小尾巴。**
这是正常现象，说明你的提示词本身已经够用了。见[大多数时候它是沉默的，并不会喋喋不休](#大多数时候它是沉默的并不会喋喋不休).

## 疑难排查

**输入 `/baishi` 或 `/拜师` 后没反应。**
先开个新会话再试一次。如果还是认不出来，多半是你的 Agent 不会把斜杠命令传给 skill——这个 skill 只能靠命令开启，在这种环境里暂时用不了。

**提示跑进文件里，或者把我的输出搞乱了。**
这是 bug：按设计，skill 禁止把提示写进交付物。如果你愿意帮忙改进这个 skill，请开一个 issue，把对话贴进去。

**想关闭小尾巴但关不掉。**
单独发一条 `stop baishi`。还在继续的话，开个 issue 帮我们改进。

## Skill 的内容

只有一个文件：[`SKILL.md`](SKILL.md)，里面有五条运行规则、10 条沉默条件，以及一条关于用户主动调整的规则。
