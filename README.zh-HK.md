# baishi 拜師

**幫你嘅 AI 回答加條小尾巴，有需要時畀啲提示詞方面嘅建議。**

[English](README.md) · [简体中文](README.zh-CN.md) · 繁體中文（香港）

「拜師」本來係「拜認師傅」嘅意思，呢度取其核心內涵，以 Skill 嘅形式，喺合適嘅時機畀你啲提示詞優化嘅小建議。

---

## 呢個 Skill 啱邊個用？

**如果你係**用 AI 查資料、寫下嘢、改下文件、plan 下行程，全部都係日常嘢，亦從來冇研究過咩「提示詞工程」，噉呢個 Skill 就係為你寫嘅。

**如果你係**靠寫提示詞搵食嘅人，或者平時已經會諗上下文、示例、輸出格式呢啲嘢，噉你大概會覺得呢個 Skill 識嘅嘢太淺喇。

## 你有冇遇過呢種情況？

你叫 AI 幫手，佢答咗，但就係可能未係好啱你心意。於是你就補一句，再補一句。幾輪之後，你終於攞到想要嘅嘢。

如果一開始就有個更啱使嘅提示詞，其實可以快好多。

拜師就係一個順手畀你啲提示詞建議嘅小 Skill。

## 呢個 Skill 大概係點嘅樣？

你照常同 AI 傾。佢偶爾會喺回答最尾加條小尾巴，順手畀你知喺當前場景可以點樣優化提示詞。

**寫文案**

> **你：** 幫我寫份產品發佈公告
>
> **AI：** *（你要嘅完整草稿）*
>
> 💡 提示詞技巧參考：呢類發佈公告，寫明目標讀者、投放渠道同語氣，初稿通常會離可用近好多；例如「為 Northwind Notes 寫一段 120 字、面向 freelance 設計師、發佈喺 Facebook 專頁、語氣溫和克制嘅發佈文案」噉講通常好使啲。

**同一件事，轉用其他語言問，譬如話英文** —— 你用咩語言，拜師畀你嘅小建議就用咩語言

> **You:** help me find recent papers on sleep and memory consolidation
>
> **AI:** *(the full answer)*
>
> 💡 A prompt phrasing tip: For a literature search like this, naming the years, the population, and what you'll do with the findings narrows the results fast — for example, "find 2023–2026 studies on sleep and memory consolidation in adults over 60, for a patient handout."

**冇咩好教嘅時候**

> **你：** 法國首都在邊？
>
> **AI：** 巴黎。

既然冇嘢好教，AI 正常答完就收工，唔會再加嘢。

## 大多數時候佢都唔出聲，唔會喋喋不休

好似下面呢啲情況，拜師都畀唔到咩好建議，所以就索性唔出聲：

- 你問嘅係一個簡單事實，冇必要為咗呢條問題去琢磨提示詞。
- 你正用 AI 做啲複雜嘢，或者同 AI 傾緊一啲情緒問題，呢個時候你唔想被偶爾彈出嚟嘅小建議打擾。
- 你要求 AI 嘅回答一定要係某個指定格式（例如 JSON、檔案、表格），為咗唔好令小提示誤入其中，都係收聲好。
- AI 諗完你條問題之後反問你，呢種情況下你嘅解釋本身已經達到優化提示詞嘅目的，唔使 Skill 再重複多嘴。
- 你原本嘅提示詞已經好夠用、達到目的，噉就唔使多講。
- 如果係 AI 自己能力所限，答得唔夠好，而唔係改提示詞可以解決嘅，呢個 Skill 都唔會有反應。

## 安裝

將下面呢句複製畀你嘅 AI，其餘佢會自己搞掂。

```
請幫我安裝呢個 Skill：https://github.com/peiguanyi/baishi-skill
```

想自己動手嘅話：

1. 下載：喺本頁撳 Code → Download ZIP，然後解壓。
2. 放置：將個資料夾放入你 agent 讀 skill 嘅目錄。
3. 重載：重啟 Agent 或者開個新對話，然後輸入 `/baishi` 或 `/拜師`。

想解除安裝，將 `baishi` 資料夾刪咗就得。

## 啟用

裝好之後，想啟用拜師，輸入下面任何一條就得：

```
/baishi
/拜师
/拜師
```

如果你開咗新對話，又想繼續用拜師，就要喺新對話入面再輸入一次指令啟用。

輸入完冇反應？可以睇下[疑難排解](#疑難排解)。

## 調整

你或者會想調整小尾巴出現嘅頻率同內容長度，直接同 Agent 講你想點就得，不過呢啲調整只喺你當前對話、今次 Skill 調用入面生效。

## 關閉

明確同 Agent 講你想停用拜師，就可以關咗佢，例如：

`stop baishi` · `no more tips` ·  `stop 拜師` · `唔使 tips` · `唔好再畀建議我喇` · `熄咗拜師`

## 重新啟用

關咗拜師之後，再輸入 `/baishi` 或 `/拜師` 就可以再開返呢個 Skill。

## 佢到底教緊啲咩

拜師畀你嘅係一條提示詞改寫建議，從來唔係一套理論。

| 常缺嘅嘢 | 提示會補上嘅 |
| --- | --- |
| 畀邊個睇 | 讀者、受眾、身份 |
| 用喺邊 | 渠道、格式、載體 |
| 有幾長 | 字數、條數、章節數 |
| 咩語氣 | 語氣、正式程度 |
| 點先算好 | 一小段你想要嘅成品例子 |
| 唔要咩 | 限制條件、排除項 |

## 常見問題

**佢會改我嘅回答嗎？**
唔會。AI 原本嘅完整回答永遠排第一位，呢個 Skill 本身唔會對 AI 嘅回答作出任何調整。

**佢係一個提示詞評分系統嗎？**
唔係。呢個 Skill 唔會去評價你嘅提示詞，佢只係喺部分情況下畀你啲建議。

**佢會將我嘅內容上載去邊度嗎？**
唔會。呢個 Skill 本質上就只係一個 Markdown 檔案，唔會執行任何程式碼，亦唔會將你嘅對話上載去邊度。

**用英文或者其他語言都用得嗎？**
用得。呢個 Skill 嘅小尾巴會用你喺對話入面所用嘅語言。

**可以同其他 Skill 一齊用嗎？**
可以。拜師只係喺你 AI 回答嘅最尾加條小尾巴，回答內容係咪由其他 Skill 搞出嚟，都唔影響拜師。

**我開咗拜師，但傾咗幾輪都未見過小尾巴。**
呢個係正常現象，代表你嘅提示詞本身已經夠用。睇下[大多數時候佢都唔出聲，唔會喋喋不休](#大多數時候佢都唔出聲唔會喋喋不休)。

## 疑難排解

**輸入 `/baishi` 或 `/拜師` 之後冇反應。**
先開個新對話再試一次。如果都係認唔到，多半係你嘅 Agent 唔會將斜線指令傳畀 skill——呢個 skill 只可以靠指令開啟，喺呢種環境暫時用唔到。

**提示跑咗入檔案入面，或者搞亂咗我嘅輸出。**
呢個係 bug：按設計，skill 唔准將提示寫入交付物。如果你願意幫手改進呢個 skill，歡迎開個 issue，將對話貼入去。

**想關咗小尾巴但關唔到。**
單獨發一條 `stop baishi`。仲係繼續嘅話，開個 issue 幫我哋改進。
